# George Prevalsky's MMA & Boxing Gym - Website

A modern recreation of the Dallas MMA & Boxing Gym website built with Next.js 14, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Fonts**: Archivo Black (headings) + Montserrat (body/nav) via `next/font/google`

## Pages

| Route | Description |
|-------|-------------|
| `/` | Homepage with hero, about, location, map, and Instagram sections |
| `/schedule` | Class schedule with trial class times and waiver links |
| `/programs` | Boxing, Muay Thai, BJJ, and Kids program details |
| `/trial-day-sign-up` | Free trial class information and sign-up steps |
| `/instructors` | Instructor bios (George Prevalsky, Kevin Kildea, Victor Ling, Yousef Alirezaei) |
| `/fighters` | Active and past fighters/champions |
| `/contact-us` | Contact info, form, and embedded Google Map |
| `/memberships` | Membership plans (hidden from nav, accessible by URL) |

## Design

- Dark, bold martial arts aesthetic
- Alternating black/white section backgrounds
- Archivo Black uppercase headings
- Mobile responsive layout
- Semi-transparent fixed navigation

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
